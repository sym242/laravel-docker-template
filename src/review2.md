# Laravel Lesson レビュー②

## Todo編集機能

### @method('PUT')を記述した行に何が出力されているか
- <input type="hidden" name="_method" value="PUT">
　<form method="PUT">のようにPUTメソッドを指定することができないため
　@method('PUT')を使用し、PUTメソッドでリクエストを送信できるようにしています
　name属性が_methodでデータが送信された場合はvalue属性の値をHTTPメソッドとして処理します。

### findメソッドの引数に指定しているIDは何のIDか
- 実際には見えないがtodoリストに登録した際にIDが自動的に割り振られます。
　findメソッドの引数のidは選択したデータに割り振られているIDです。
　
### findメソッドで実行しているSQLは何か
- select * from `todos` where `todos`.`deleted_at` is null

### findメソッドで取得できる値は何か
- 選択したidでtodosテーブルのdeleted_atに日付が入っていないレコード全てを取得します。

### saveメソッドは何を基準にINSERTとUPDATEを切り替えているのか
- INSERTは新規作成の場合で、UPDATEは既存のデータがある場合。

## Todo論理削除

### traitとclassの違いとは
- クラスの継承とは異なり1つのクラスに複数のトレイトを追加することができます。
　またトレイト自体はインスタンス化できません。

### traitを使用するメリットとは
- 複数のクラスで共通の機能を再利用でき、複数のトレイトを同時に利用することもできます。
　これにより、異なる機能を組み合わせた柔軟なクラスの設計が可能になり、
　変更や修正も1箇所で済むようになります。

## その他

### TodoControllerクラスのコンストラクタはどのタイミングで実行されるか
- ルートメソッドが実行される際のコントローラのインスタンスが生成される時に実行されます。

### RequestクラスからFormRequestクラスに変更した理由
- FormRequestクラスはフォームデータのバリデーションを行うために使用し、
　このクラスにバリデーションルールをまとめて記載することができ、
　バリデーションをクラス毎に分けて管理することができます。

### $errorsのhasメソッドの引数・返り値は何か
- $errors->has('入力欄のname属性')を引数にし、バリデーションでname属性を指定しています。
　has()の返り値はその入力欄でバリデーションエラーが発生しているか判定し、
　エラーがあればtrue,なければfalseを返します。

### $errorsのfirstメソッドの引数・返り値は何か
- $errors->first('入力欄のname属性')を引数にし、バリデーションのエラーを取得したいname属性を指定します。
　first()の返し値は入力欄で最初に発生したエラーメッセージを返します。

### フレームワークとは何か
- 土台となる仕組みや枠組みのことで、よく使う機能や構造があらかじめ用意されていて、
　それを使って開発をスムーズにするためのものです。

### MVCはどういったアーキテクチャか
- Model、View、Controllerのアプリケーションを3つの役割に分けて設計すること。
　役割ごとに処理を書くことでコードの可読性・保守性・拡張性を上げられます。

### ORMとは何か、またLaravelが使用しているORMは何か
- ORMとはデータベースのレコードをオブジェクトとして扱える仕組みのことで、
　SQLを直書きしなくても、PHPのクラス・メソッドでDB操作できるようになります。
　Laravel で使用しているのはEloquentというORMで、モデルクラスとデータベースのテーブルを1対1で対応させて、
　簡単にCRUD操作ができます。

### composer.json, composer.lockとは何か
- composer.jsonはプロジェクトがどのようなライブラリや設定を必要としているかを明示するための設定ファイルで、
　composer.lockはcomposer.json で指定されたライブラリの正確なバージョンや
　依存関係の詳細をロック（固定）して記録しておくファイルです。

### composerでインストールしたパッケージ（ライブラリ）はどのディレクトリに格納されるのか
- プロジェクトのvendorディレクトリに格納されます。
